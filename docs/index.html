03 / About the data

Methodology & limitations

Source: OpenIntro nycflights, a random sample of 32,735 flights from JFK, LGA and EWR in 2013; originally credited to H. Wickham, nycflights13 (2014). The website stores the dataset locally with its source attribution. Flight values are not live.

Late arrival: strictly more than 15 minutes after the scheduled arrival. Percentages exclude records missing an arrival delay. Missing delays are not automatically classified as cancellations.

Interpretation: airline and airport rates are unadjusted for route mix, season, weather or other confounders. Historical associations are not proof of causation or measures of current airline performance.

Built with vanilla JavaScript, native SVG, HTML and CSS. No database, API key, account, or Python runtime required.
